# 隐私说明

本项目为**单人本地自托管**学习工作台（ADR-001）。以下说明数据存在哪里、会离开本机什么、以及如何删除。

## 数据存在哪里

- 学习数据全部在本地 SQLite（`STUDYFORGE_DB` 指定，默认 `backend/studyforge.sqlite3`）和后端工作目录的资料文件夹；无账号体系，不上传学习记录到任何云端。
- 上传的代码/日志以文本存入数据库（便于整库备份），不散落为小文件；原始 PDF/资料文件保存在本地资料目录，数据库只记引用。
- 除用户自己配置的 LLM 网关（见下）外，应用不会向第三方发送学习内容；没有遥测、统计上报或自动更新检查。

## 密钥与凭据

- API Key 只通过环境变量或被 Git 忽略的 `.env` 配置；`.env`、`*sqlite3`、个人资料目录均在 `.gitignore`，不会被提交。
- 上传内容经过凭据扫描提示，但扫描结果不回显、不入库；文件名禁止路径穿越。
- 网页**不执行**上传代码（ADR-002）：只做文本解析与静态分析；日志是用户提供的证据，不会被标记成服务器实测结果。

## 模型调用

- 真实模型调用只发往用户在配置中指定的供应商（Anthropic / Ollama / OpenAI 兼容网关）；`fake` 供应商不联网。
- 费用为估算值并受预算上限保护；调用失败不影响已有项目和资料浏览。
- 评审、变式题、自由学习问答均为显式动作；模型失败时返回受控错误，**不伪造**答案、题目或评审。

## 删除与保留

- 删除一次提交（`DELETE /api/submissions/{id}`，前端提交详情页）会级联删除其代码/日志文本与全部评审记录。
- 删除资料前做跨项目引用计数：仍有项目引用时只解绑，不物理删除文件；无引用时清理文件、分块与全文索引。
- 项目归档是只读保留，不删除课程、答题、复习历史；没有项目硬删除接口。
- 备份即复制数据库（含全部提交、知识、评审）与资料目录；恢复与回滚流程见 [`OPERATIONS.md`](OPERATIONS.md)。

## 网页抓取

- 资料 URL 抓取拒绝内网/私有地址与重定向到内网的跳转（SSRF 防护），只允许 http/https；抓取内容视为不可信数据处理。

## 不属于本产品的承诺

- 本机服务没有登录保护：不要把开发服务或 API 文档暴露到不可信网络（README 运行说明）。
- 备份文件本身含全部个人数据：备份目录同样不要提交 Git、不要同步到不可信位置。
