# 从 Markdown 文件夹导入课程

在「创建课程」页选择一个本地文件夹，直接建成课程，不经过 AI 生成。
子文件夹变成模块（章节），`.md` 文件变成课时。

## 目录结构

```
my-course/
├── course.json            # 可选：{"title": "课程名", "description": "简介"}
├── 01-第一章/              # 子文件夹 = 一个模块
│   ├── 01-注意力机制.md    # .md 文件 = 一个课时
│   └── 02-多头注意力.md
├── 02-第二章/
│   └── 01-位置编码.md
└── 附录.md                 # 根目录的文件：全部放进一个模块
```

## 规则

- **排序**：文件名/文件夹名开头的数字前缀（`01-`、`02_`、`3.`）决定顺序，
  前缀不显示在标题里；没有前缀的按字母顺序排。
- **课时标题**：取文件内第一个 `# ` 标题；没有标题的用文件名。
- **模块标题**：取文件夹名；根目录的零散文件放进一个与课程同名的模块。
- **课程标题**：`course.json` 的 `title` 优先，其次是文件夹名。
- **忽略**：非 `.md` 文件（图片、txt 等）会被跳过；暂时不支持导入图片，
  文中的图片引用会原样保留但无法显示。
- **限制**：最多 100 个文件，单个文件 200 KB，总计 5 MB。

## 导入后

- 课时没有练习题：去课程页的「题目」区用 **AI 出题** 按题型/数量补。
- 所有内容都可手动修改：课时页点「编辑」改正文，课程页可改标题简介。
